# Views

## Manifest link must be added manually (vite-plugin-pwa + Laravel)
vite-plugin-pwa only injects the <link rel="manifest"> and theme-color/iOS meta tags when there is an index.html entry — Laravel has none, so nothing is injected. Keep the manual <link rel="manifest" href="/build/manifest.webmanifest"> plus theme-color, apple-mobile-web-app-capable, and mobile-web-app-capable metas in app.blade.php, otherwise the PWA cannot be installed on phones. manifest.webmanifest is only generated by `npm run build` (devOptions.enabled=false), so in dev the link 404s harmlessly.
